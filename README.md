✨ About The Project

TheTechDuo brings together modern web technologies and software engineering to deliver practical solutions for businesses, researchers, and educational institutions.

Our platform showcases three major software products:

GeoSense Pro – Advanced mineral identification and geological data processing.
VisionID – Face recognition application built with Python and OpenCV.
EduTrack – School management software with student records and attendance tracking.
💎 Featured Project: GeoSense AI

GeoSense is an advanced mineral classification tool that identifies potential minerals based on their physical properties.

Key Features
Mineral identification using physical characteristics.
Hardness analysis using the Mohs scale.
Density-based classification.
Lustre and streak colour matching.
Top three matching mineral predictions.
Browser-based interactive demonstration.
Supported Properties
Property	Description
Hardness	Mohs hardness scale (1–10)
Density	Mineral density (g/cm³)
Lustre	Surface appearance
Streak	Colour of mineral powder
